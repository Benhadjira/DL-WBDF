# DL-WBDF
Deep Learning-Assisted Weak Beam Identification in Dark Field X-ray Microscopy

This repository provides the implementation for DL-WBDF, a deep learning-based pipeline designed to automatically identify weak-beam conditions in Dark Field X-ray Microscopy (DFXM) rocking curve datasets. The project supports efficient, automated classification of beam conditions to assist in the 3D reconstruction of dislocation structures in crystalline materials.

This code was developed as part of my PhD research at Université Grenoble Alpes and the ID03 beamline at the European Synchrotron Radiation Facility (ESRF).
